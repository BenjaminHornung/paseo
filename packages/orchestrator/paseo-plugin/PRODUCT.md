# Orchestrator-Einstellungen

Benutzer: lokaler Entwickler, der sein bestehendes Paseo-Setup bedient.
Ziel: Rollen-/Modellrouting, Reasoning, Decisions, Keys und Budgets ohne JSON-
Handarbeit kontrollieren. Änderungen wirken tatsächlich auf neue Controller-
Aufträge; aktive Aufträge bleiben auf ihrer geprüften Konfiguration.

Eine Erweiterung von Paseos bestehender Settings-Oberfläche. Keine eigene Marke,
keine Marketingseite, keine zusätzlichen Dashboard-Kennzahlen.
